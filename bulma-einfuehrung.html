Bulma CSS

Eine kurze & klare Einführung

Was ist Bulma?

Bulma ist ein modernes, kostenloses CSS-Framework. Es hilft dir, schöne und responsive Webseiten zu bauen – ohne dass du viel eigenes CSS schreiben musst.

Im Gegensatz zu manchen anderen Frameworks kommt Bulma ohne JavaScript aus. Du bindest einfach eine CSS-Datei ein und kannst direkt mit fertigen Klassen arbeiten.

Die Klassen haben klare, sprechende Namen wie button, card, hero, columns oder notification.

Die wichtigsten Vorteile

  • Einfach – klare Klassennamen
  • Modern – basiert auf Flexbox
  • Leicht – kein JavaScript nötig
  • Kostenlos – Open Source (MIT-Lizenz)
  • Responsive – funktioniert auf Handy & Desktop

Stylesheet einbinden

Am einfachsten bindest du Bulma über ein CDN ein. Füge dazu einfach diese Zeile in den <head> deiner HTML-Datei ein:

Verwendetes Stylesheet (CDN) 

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/npm/bulma@1.0.4/css/bulma.min.css">

Das war’s schon. Ab jetzt stehen dir alle Bulma-Klassen zur Verfügung.

Kleine Beispiele

So einfach sieht der Einsatz von Bulma aus:

Buttons

<button class="button is-primary">Primary</button>
<button class="button is-link">Link</button>
<button class="button is-info">Info</button>

Hinweis-Box

<div class="notification is-primary is-light">
  Das ist ein Hinweis.
</div>
Das ist ein Hinweis.

Spalten-Layout

<div class="columns">
  <div class="column">Spalte 1</div>
  <div class="column">Spalte 2</div>
  <div class="column">Spalte 3</div>
</div>

Was Bulma besonders macht

Nur CSS

Kein JavaScript nötig. Einfach einbinden und loslegen.

Responsive

Layouts passen sich automatisch an Smartphone, Tablet und Desktop an.

Klare Namen

Klassen wie is-primary oder has-text-centered sind selbsterklärend.
